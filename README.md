# bitmask_learning_tool
Claude generated Python file to help me master bitmasks in C/C++

Create C type statements and use bitwise operators (&,|,~= etc.) to form new values.
Output is shown in hex and binary.

Includes tools to view and wipe variables, quizzes, an idiom "cheat sheet page" and lots of other goodies.

written using claude code opus 5.  7-31-26

to run the script: uv run bitwise.py

For more info read the Claude generated README.MD file in this repo (the "other" readme file, not this one) and/or start the program and at the >> prompt type help
